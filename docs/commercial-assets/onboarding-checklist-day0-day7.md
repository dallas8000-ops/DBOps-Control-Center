# Onboarding Checklist (Day 0 to Day 7)

## Day 0 - Kickoff
- Confirm business owner and technical owner.
- Confirm deployment target and network constraints.
- Validate access to GitHub, Render, and database environment.
- Confirm RBAC role mapping (DBA, Analyst, Viewer).

## Day 1 - Environment Baseline
- Deploy baseline stack to staging.
- Set JWT and API environment variables.
- Verify health endpoint and frontend connectivity.
- Run migration chain and seed demo data.

## Day 2 - Security and Access
- Create initial DBA and role-based user accounts.
- Validate disabled-user behavior and audit visibility.
- Confirm password reset and account lifecycle controls.

## Day 3 - Incident Workflow Setup
- Configure incident ownership conventions.
- Validate incident create/edit/resolve flows.
- Confirm operational summary metrics align with expectations.

## Day 4 - Reporting Setup
- Finalize initial report whitelist.
- Validate report run and CSV export behavior.
- Configure at least one scheduled report and validate logs.

## Day 5 - Runbook and Handoff Draft
- Document common operator tasks.
- Document rollback and redeploy procedure.
- Record known limitations and escalation points.

## Day 6 - Stakeholder Walkthrough
- Run DBA workflow demo.
- Run incident-to-report workflow demo.
- Capture enhancement backlog and ownership.

## Day 7 - Go-live Readiness Review
- Confirm support tier and SLA.
- Confirm monitoring and backup checks.
- Sign off acceptance checklist and next-30-day plan.
