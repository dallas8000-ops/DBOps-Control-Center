# DBOps Control Center Pricing Sheet

## Tier 1 - Launch
- Price: USD 8,000 one-time implementation
- Team size: up to 5 users
- Included:
  - Initial deployment (Render or equivalent)
  - JWT/RBAC setup
  - Incident workflow setup
  - Whitelisted report pack (up to 3 reports)
  - Basic handoff session (2 hours)
- Exclusions:
  - SSO/OIDC integration
  - Custom enterprise security controls
  - 24x7 support

## Tier 2 - Growth
- Price: USD 14,000 one-time implementation
- Team size: up to 20 users
- Included:
  - Everything in Launch
  - Scheduled reports setup
  - Audit and admin workflow tuning
  - CI checks for lint/test/build
  - 2 workflow refinement sessions
- Exclusions:
  - Dedicated environment management across multiple regions
  - Full observability stack onboarding

## Tier 3 - Scale
- Price: USD 20,000 one-time implementation
- Team size: 20+ users
- Included:
  - Everything in Growth
  - SSO/OIDC integration spike and implementation
  - Advanced report package (up to 10 reports)
  - Runbook and operational readiness package
  - Stakeholder enablement workshop
- Exclusions:
  - Custom legal/compliance certification projects
  - Data warehouse migration work

## Monthly Support Add-ons
- Essential: USD 800/month
- Standard: USD 1,500/month
- Premium: USD 2,500/month

## Commercial Notes
- Prices assume one production environment and one staging environment.
- Third-party licensing costs are billed separately.
- Change requests outside agreed scope are estimated and approved before work starts.
